# HGM v0.1 Release Notes

## Release identity

**HGM v0.1** — Hypergraph Manifold / Hyperset Probability Matrix Expansion foundation release.

## Summary

HGM v0.1 introduces an additive HGM/HPME package under:

```text
mnemonic_cortex/hypergraph_manifold/
```

It provides typed foundations, probability expansion, hyperedge binding, manifold routing, SPCP procedural memory scaffolds, trace-safe QDT/WM bridge planning, evaluation metrics, write-permission previews, simulation-mode transaction logs, pipeline benchmarks, runtime integration readiness gates, and final release consolidation.

## Stage highlights

- **HGM-0A:** foundation dataclasses, enums, shape contracts, validation, traces.
- **HGM-0B:** probability expander, normalization, top-k scenario extraction.
- **HGM-1:** hyperedge scenario binder, coherence, conflict, opportunity detection.
- **HGM-2:** manifold chart routing, geometry distance wrappers, depth retrieval bridge.
- **HGM-3:** SPCP procedural memory, action-sequence storage, advisory robotics planning.
- **HGM-4:** dry-run QDT/WM bridge payloads and shared slot-lattice hook contracts.
- **HGM-5:** deterministic embedding scaffold, bridge quality metrics, integration scoring.
- **HGM-6:** write-permission gate, transaction preview, rollback-safe commit plan.
- **HGM-7:** simulation-mode write execution scaffold, transaction log, recovery verification.
- **HGM-8:** runtime embedding scaffold, safe write replay, end-to-end pipeline benchmark.
- **HGM-9:** runtime integration evaluation, slot-lattice replay, production-readiness gate.
- **HGM-10:** API freeze, release consolidation, documentation pack, roadmap.

## Safety posture

HGM v0.1 is additive and evaluation-first. It does not perform live QDT/WM writes, mutate memory internals, execute robotics actions, call networks, or enable production execution.

## Testing

HGM-10 preserves the HGM-0A through HGM-10 compatibility test chain.
